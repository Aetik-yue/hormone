# Hormone 课表 v1.2.3 更新日志

## 应用内更新

- 启动 App 后自动检查 GitHub 最新正式版本，每 24 小时最多检查一次；无更新或网络异常时不打扰用户
- 设置页新增“应用更新 → 检查更新”，可随时手动检查
- 更新弹窗展示版本号、更新内容和 APK 大小
- 支持应用内下载、进度显示、取消下载和失败重试
- 下载完成后校验 SHA-256，校验通过后打开 Android 系统安装确认页
- 修复并发检查可能导致的重复请求，并验证校验文件对应当前 APK

## 发布与兼容性

- Android 版本号更新为 `1.2.3+23`，最低支持 Android 7.0（API 24）
- 接入固定签名发布流程，自动生成 APK、AAB、SHA-256 文件并发布 GitHub Release
- 沿用与已发布 v1.2.2 完全相同的签名证书，密钥独立保存并固定到 CI；不需要因本次签名配置卸载旧版
- 数据库 schema 未变更，无需迁移；相同签名下覆盖升级保留原有课表与设置

## 升级说明

- 安装本版本后，后续新版本可通过 App 内更新入口下载安装
- 普通 Android 应用仍需用户在系统安装页确认；首次使用可能需要允许“安装未知应用”
- 若系统提示签名不兼容，请先在旧版本设置中导出课表备份，再卸载旧版、安装新版并恢复备份；不要未备份就卸载
- 更新源为 GitHub Releases，访问 GitHub 不畅时请稍后重试
