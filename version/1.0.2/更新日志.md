# Hormone 课表 v1.0.2 更新日志

## 新功能

- **教务系统导入**：设置 → 从教务系统导入，WebView 内登录学校教务系统后一键抓取课表
  - 重庆大学（金智教务 my.cqu.edu.cn）
  - 江西财经大学（青果教务 xk.jxufe.cn）
- **课程详情弹窗**：点击课程卡片查看详情（教师、教室、周次、备注），长按进入编辑
- **主界面学期切换**：点击顶部学期名即可切换学期
- **节次时间自定义**：设置页可逐节修改开始时间，支持恢复默认
- **数据导出备份**：一键导出全部学期和课程为 JSON 文件
- **主题持久化**：深色/浅色/跟随系统选择重启后保留

## 修复

- 移除首次启动的演示课程，空状态改为「尚未导入课程」引导
- 修复 WebView 教务系统登录页显示不全（移动端 UA + viewport 注入）
- 修复 Android 9+ 无法加载 HTTP 教务网站（usesCleartextTraffic）
- 修复 WebView 抓取 JSON 双重编码导致解析失败
- 修复课程导入星期/节次解析错误（重写 DOM + 文本双策略解析器）

## 技术改进

- 学校适配器架构：新增学校只需实现一个 Adapter 类
- WebView 调试弹窗：抓取失败时显示页面 DOM 结构，便于适配新学校
- Gradle 兼容性修复（afterEvaluate / flutter ext / Kotlin languageVersion）
