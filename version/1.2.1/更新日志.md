# Hormone 课表 v1.2.1 更新日志

## 课表布局

- 缩短主页顶栏和周次选择栏，减少顶部空间占用
- 将“今日课程”“课程抓取说明”“设置”整合到“更多”菜单，保留课程搜索为高频快捷入口
- 左侧节次时间轴由 48dp 缩窄到 40dp，为七天课程列留出更多空间

## 教务导入

- 新增井冈山大学（金智智慧校园）专用适配器，支持接口、DOM、iframe 和菜单导航多级回退
- 更新重庆大学统一认证入口与课表页识别规则
- 增强江西财经大学适配器，兼容新版 data 属性表格、传统 rowspan 表格、iframe 和课程安排入口导航
- 增强南昌大学适配器，使用官方统一认证入口，兼容强智接口的多种学期编码、响应字段、DOM 和菜单导航
- 高校目录统一为 43 所学校并按校名拼音排列，支持通过学校名、拼音、系统名和 URL 搜索
- 移除“重点高校/其他学校”的视觉分组，让所有受支持学校在同一目录中平等展示

## 界面与质量

- 补充紧凑课表布局、学校目录、江西财经大学、南昌大学和井冈山大学适配器回归测试
- 更新 README 的功能说明与学校适配开发指引
- 清理静态分析配置中已经弃用的 legacy plugins 选项

## 构建

- Android 版本号更新为 `1.2.1+21`
