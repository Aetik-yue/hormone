# Hormone 课表 v1.0.4 更新日志

## 体验优化

- **左右滑动切换周数**：课表区域支持左右滑动手势，左滑下一周、右滑上一周
- **界面更紧凑**：压缩周选择器和星期表头留白，课表内容区域更大更突出

## 修复

- 修复重庆大学教务导入 JS 解析器（重写为 DOM 扫描 + 文本正则双策略，支持多段周次格式）
- 修复江西财经大学教务系统 URL 错误（改为 http://xk.jxufe.cn）
- 修复 Android 9+ 无法加载 HTTP 教务网站（添加 usesCleartextTraffic）
- 修复 WebView 抓取 JSON 双重编码解析失败
- 修复 WebView 登录页显示不全（移动端 UA + viewport 注入）
- 移除首次启动演示课程，空状态改为「尚未导入课程」引导
