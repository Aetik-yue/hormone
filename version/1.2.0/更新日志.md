# Hormone 课表 v1.2.0 更新日志

## 数据备份闭环

- **导出备份走系统分享**：一键导出全部学期与课程为 JSON，通过系统分享面板保存到下载/网盘/微信等，不再写入用户打不开的应用私有目录
- **从备份恢复**：设置页新增「从备份恢复」，先校验再确认、单事务全量替换，恢复学期、课程、激活学期与手动周次覆盖，失败不留半截数据

## 课前提醒

- 新增「课前提醒」开关与提前分钟数（5/10/15/30）
- 每天每节课开始前推送通知，随课表/节次变化自动重排，跨重启保留，回到前台与跨午夜自动补排
- Android 13+ 打开开关时请求通知权限

## 课表视图

- **今日视图**：一键查看今日课程时间线，标注“进行中 / 未开始 / 已结束”
- **课程搜索**：按名称 / 教师 / 教室检索，结果可直接跳到该课程所在周
- 节次上限扩展为 **16 节**，课表支持纵向滚动，星期栏保持固定

## 课程导入

- **学校搜索**：教务导入页按学校名 / 系统名 / URL 筛选，985 高校与通用入口分开管理
- **导入模式**：整体替换 / 合并追加两种模式，合并时与现有课表冲突的课程标红并横幅提示
- **执行确认**：导入前二次确认，明确将影响多少门现有课程
- **上课时间**：WebView 导入自动按节次时间表补全开始/结束钟点，桌面小组件显示具体时间
- 预览列表按星期分组、支持全选，修复 debug 构建下非法星期数据直接崩溃的问题

## 小组件与体验

- 小组件刷新集中化：数据变化、回到前台、跨过午夜都会自动更新今日课程，不再停留在昨天
- 课表节高随系统字号缩放，课程卡片带可读语义标签（无障碍）
- 移除从未启用的 sentry_flutter 与 flutter_animate 依赖，精简安装包

## 构建与质量

- Android 版本号更新为 `1.2.0+20`
- 完成代码生成、严格静态检查、117 项全量测试及 Android APK/AAB 发布构建
