# Hormone 课表 v1.1.0 更新日志

## 新功能

- **教务系统导入**：WebView 内登录学校教务系统，一键抓取课表
  - 重庆大学（金智教务 my.cqu.edu.cn）
  - 江西财经大学（青果教务 xk.jxufe.cn）
- **课程详情弹窗**：点击课程卡片查看详情，长按进入编辑
- **主界面学期切换**：点击顶部学期名即可切换学期
- **节次时间自定义**：设置页可逐节修改开始时间
- **数据导出备份**：一键导出全部学期和课程为 JSON 文件
- **主题持久化**：深色/浅色/跟随系统选择重启后保留

## 体验优化

- 左右滑动切换周数
- 压缩周选择器和星期表头留白，课表区域更大
- 移除首次启动演示课程，空状态改为「尚未导入课程」引导

## 修复

- 修复 SQLite 动态库缺失导致的启动崩溃
- 修复桌面小组件在课程增删改后不刷新
- 修复 WebView 教务系统登录页显示不全
- 修复 Android 9+ 无法加载 HTTP 教务网站
- 修复课程导入星期/节次解析错误
- 修复 jni 包 ndkVersion 为 null 导致构建失败

## 技术改进

- 学校适配器架构：新增学校只需实现一个 Adapter 类
- Gradle 兼容性修复（afterEvaluate / flutter ext / Kotlin / NDK）
- CI release workflow 修复（双平台图标生成）
