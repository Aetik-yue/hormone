# Hormone 课表 v1.2.5 更新日志

## 更新下载优化

- 按手机架构选择较小的安装包，减少更新所需流量；继续保留通用 APK，兼容旧版更新器。
- 下载时显示进度和传输速度，安装前校验安装包大小与 SHA-256。
- 有备用下载源时，连接失败、长时间无进展或持续低速会自动切换；接近完成时保留已有进度。
- 下载弹窗保留明确的取消入口，避免误触返回键后找不到下载进度。
- 改善取消与失败重试流程；安装授权完成或取消系统安装后，可复用已下载的安装包重试，无需重复下载。
- 支持配置自有下载源与 GitHub 备用线路。本版本默认仍使用 GitHub，尚未接入国内镜像。

## 节次时间设置

- 修改第一节课开始时间后，后续节次自动顺延。
- 保留各节课时长及课间间隔，减少逐节调整的操作。

## 版本与升级

- Android 版本号更新为 `1.2.5+25`，最低支持 Android 7.0（API 24）。
- 沿用固定签名，支持从签名一致的旧版本覆盖升级；数据库结构未变更。
- 旧版更新器仍下载通用包；升级到本版本后，后续更新将自动选择对应架构的小包。

## 下载

- 不确定手机架构时请选择 `hormone-v1.2.5-android.apk`（通用包）。
- ARM64 手机可选择 `hormone-v1.2.5-arm64-v8a.apk`；ARM32 手机选择 `hormone-v1.2.5-armeabi-v7a.apk`。
- `hormone-v1.2.5-x86_64.apk` 用于 x86 64 位 Android 设备及模拟器。
- `.aab` 不能直接在手机上安装；`.sha256` 是对应 APK 的完整性校验文件。
